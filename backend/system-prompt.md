 API-endpoints (för utvecklare)

Generiska REST-endpoints (fungerar för alla tabeller)
GET /api/{table} - Hämta alla rader
GET /api/{table}/{id} - Hämta specifik rad
POST /api/{table} - Skapa ny rad
PUT /api/{table}/{id} - Uppdatera rad
DELETE /api/{table}/{id} - Ta bort rad

Exempel:
GET /api/films - Alla filmer
GET /api/films/5 - Film med ID 5
POST /api/users - Skapa användare
GET /api/showings?filmId=3 - Visningar för film 3

Autentisering
POST /api/login - Logga in
GET /api/login - Kontrollera status
DELETE /api/login - Logga ut
POST /api/forgot-password - Glömt lösenord
POST /api/reset-password - Återställ lösenord

Bokningar
POST /api/create-booking - Skapa bokning
GET /api/remote-booking/{showingId} - Uppdatera visning
GET /api/book-sse/{showingId} - Live-uppdateringar

Filmer
GET /api/comingSoon - Filmer inom 30 dagar

Kommunikation
POST /api/send-email - Skicka bokningsbekräftelse
POST /api/send-confirm/{table} - Skapa post och skicka bekräftelse

AI-assistent
POST /api/chat - Chatt med Adam
